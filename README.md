## ✨ Key Features

- 🗣️ **Trilingual** — French · English · Yemba (Yɛmba)
- 🤖 **Chatbot AzA** — 40 FAQ in 3 languages with Web Speech voice support
- 📸 **Photo Gallery** — 16-slide carousel of campaign actions
- 📰 **Press Coverage** — Chronological press review (7 sources)
- 📅 **Live Ticker** — Events + live Dschang weather (Open-Meteo)
- 🎥 **YouTube** — Campaign video from @DSCHANG2026
- 📝 **Netlify Forms** — Contact & supporter sign-up
- ⚡ **Fast** — Self-contained SPA, no external dependencies

## ⚡ Quick Start

### View the live site
Visit [tessa2026.netlify.app](https://tessa2026.netlify.app)

### Clone the repository
```bash
git clone https://github.com/SuperMatrixi/Drilling-Mayor2.git
cd Drilling-Mayor2
```

### Add images
1. Place your images in the appropriate `assets/images/` subfolder
2. Copy them to `src/assets/images/` for deployment
3. Commit and push — Netlify auto-deploys in ~60 seconds

See **[docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)** for detailed deployment instructions.
